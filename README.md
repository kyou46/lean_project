# LEAN レポート課題 - 確率論におけるマルコフの不等式およびチェビシェフの不等式の形式化

## 問題選定について：

理学部4回生の卒業講究で確率論を専攻している為、LEAN という難しい定理証明支援系の言語に慣れる練習として確率論の定理を形式化してみたいと考えた。最初は一学期中輪読している教科書『確率解析（楠岡）』の中心的なテーマであるマルチンゲール関連の定理を形式化しようと思ったが、予備知識等の準備が多く、なかなか手が付かず諦めた。それから、確率論で非常に綺麗で有名な「中心極限定理」を実装しようと思い、少し調べたところで微積分の計算量がかなり膨大なことがわかり、また諦めた。最終的に、確率論の中でも比較的に易しい対象である「マルコフの不等式」と「チェビシェフの不等式」を形式化することになったのである。

## 形式化した定理

今回のプロジェクトでは、確率論における基本的な不等式であるマルコフの不等式とチェビシェフの不等式を形式化した。

### マルコフの不等式

可積分な確率変数 $`X`$ と $`\varepsilon > 0`$ に対して、

$$
P(|X| \geq \varepsilon)
\leq
\frac{E[|X|]}{\varepsilon}
$$

が成り立つ。

### チェビシェフの不等式

二乗可積分な確率変数 $`X`$ と $`\varepsilon > 0`$ に対して、

$$
P(|X-E[X]| \geq \varepsilon)
\leq
\frac{\text{Var}(X)}{\varepsilon^2}
$$

が成り立つ。

## 形式化の手法

このプロジェクトでは Mathlib の `ProbabilityTheory` と `MeasureTheory` を主なツールとして、自力でマルコフの不等式（とチェビシェフの不等式）の証明の形式化を試みた。数学的には難しくないが、期待値や確率を一般的なルベーグ積分と置き換え、測度論のツールを用いて数多くの不等式や式変形を示していく構成である。マルコフの不等式の証明においては、まず $`\{\omega \mid |X(\omega)| \geq \varepsilon\}`$　に対応する指示関数を導入し、各点で不等式評価を行い、積分の単調性より積分した結果も同じように不等式が成り立つことを示した。

また、チェビシェフの不等式はマルコフの不等式の系として証明を行った。$`Y = (X - E[X])^2`$ を構成し、式変形によってマルコフの不等式に帰着するアプローチを採用した。

## 難しかったところ・面白かったところ：

分かってはいたものの、ごく簡単で直感的な定理の形式化でもかなり丁寧に書き下さないと証明が成り立たないと強く実感した。さらに、普通に数学の議論をするとき無視されがちな仮定などでも、ちゃんと一つ一つ漏れなく定理の前提に入れないと途中で詰むこともやりながら体験した。こういった形式化ならではの難しさも逆に面白く感じた。数学の勉強において「なんとなく雰囲気はわかるが腑に落ちない瞬間」というのはよくある事で、形式化を通してどの条件が証明のどの部分に対応するかがはっきり見えるようになる気がして、自分の理解も共に深まると考えている。もし将来にまた LEAN と形式化を携わる機会があれば、個人の勉強で抽象的な概念や理解しづらいところを形式化を通じて確かめたいと思っている。

## 工夫したところ：

* 全体的に書きながら Mathlib のドキュメントやソースコードから、目的に合った既存の補題（Lemma）を探し出すプロセスに苦労した。この過程を通じて LEAN に慣れていった手応えがかなりある。
* 不等式の主張では、不等号の左辺と右辺の型が一致しないとエラーが出る。なので非負実数を `ENNReal.ofReal` などで実数に変化することが大事である。
* マルコフの不等式に $X$ が可積分である仮定を忘れてはならない。積分の単調性（`integral_mono`）を用いる時、両辺の被積分関数が可積分であることを示す必要があるからである。
* 式を展開するときは `ring` が便利である。
* 普段の手計算では省略されがちだが、絶対値を外したりつけたりする度に注意しないといけない。
* $X$ が二乗可積分であることから Var($X$) の可積分性および可測性を示すことは意外と面倒くさかった。長い計算を LEAN が読める最低限に減らす工夫が大事だと感じだ。
