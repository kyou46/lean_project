# LEAN レポート課題 - 確率論におけるマルコフの不等式およびチェビシェフの不等式の形式化

## 問題選定について：

理学部4回生の卒業講究で確率論を専攻している為、LEAN という難しい定理証明支援系の言語に慣れる練習として確率論の定理を定式化してみたいと考えた。最初は一学期中輪読している教科書『確率解析（楠岡）』の中心的なテーマであるマルチンゲール関連の定理を定式化しようと思ったが、予備知識等の準備が多く、なかなか手が付かず諦めた。それから、確率論で非常に綺麗で有名な「中心極限定理」を実装しようと思い、少し調べたところで微積分の計算量がかなり膨大なことがわかり、また諦めた。最終的に、確率論の中でも比較的に易しい対象である「マルコフの不等式」と「チェビシェフの不等式」を定式化することになったのである。

## 形式化の手法

このプロジェクトでは Mathlib の `ProbabilityTheory` と `MeasureTheory` を主なツールとして、自力でマルコフの不等式（とチェビシェフの不等式）の証明の形式化を試みた。数学的には難しくないものの、期待値や確率を積分と置き換え、測度論のツールを用いて数多くの不等式や式変形を示していく構成である。

## 難しかったところ・面白かったところ：

分かってはいたものの、ごく簡単で直感的な定理の形式化でもかなり丁寧に書き下さないと証明が成り立たないと強く実感した。さらに、普通に数学の議論をするとき無視されがちな仮定なども、一つひとつちゃんと定理の前提に入れないと途中で詰むこともわかった。こういった形式化ならではの難しいところも逆に面白く感じた。数学の勉強において「なんとなく雰囲気はわかるが腑に落ちない瞬間」というのはよくある事で、形式化を通してどの条件が証明のどの部分に対応するかをはっきり見えるようになる気がして、自分の理解も共に深まると考えている。

## 工夫したところ：

* 全体的に書きながら Mathlib のドキュメントやソースコードから、目的に合った既存の補題（Lemma）を探し出すプロセスに苦労した。この過程を通じて LEAN に慣れていった手応えがかなりある。
* 不等式の主張では、不等号の左辺と右辺の型が一致しないとエラーが出る。なので非負実数を `ENNReal.ofReal` などで実数に変化することが大事である。
* マルコフの不等式に $X$ が可積分である仮定を忘れてはならない。積分の単調性（`integral_mono`）を用いる時、両辺の被積分関数が可積分であることを示す必要があるからである。
* 式を展開するときは `ring` が便利である。
* 普段の手計算では省略されがちだが、絶対値を外したりつけたりする度に注意しないといけない。
