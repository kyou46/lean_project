# LEAN レポート課題 - 確率論におけるマルコフの不等式の形式化

問題選定の理由：理学部4回生の卒業講究で確率論を専攻している為、LEAN に慣れる練習として確率論の定理を定式化してみたいと思いました。最初は一学期中輪読している教科書『確率解析（楠岡）』の一番テーマであるマルチンゲール関連の定理を定式化しようと思いましたが、予備知識等の準備が多く、なかなか手が付かず諦めました。それから、確率論で非常に綺麗で有名な「中心極限定理」を実装しようと思い、少し調べたところで微積分の計算がかなり大変そうなことがわかり、また諦めました。最終的に、確率論の中でも比較的に易しい対象である「マルコフの不等式」を定式化することになったのです。

工夫したところ：

・不等式の主張では、不等号の左辺と右辺の型が一致しないとエラーが出る。なので非負実数を ENNReal.ofReal などで実数に変化することが大事である。
・マルコフの不等式に X が可積分である仮定を忘れてはならない。積分の単調性（integral_mono）を用いる時、両辺の被積分関数が可積分であることを示す必要があるからである。
